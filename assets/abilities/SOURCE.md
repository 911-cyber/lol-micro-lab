# Ability images and names

52 PNGs: 40 Q/W/E/R icons, 10 passive icons, SummonerFlash and SummonerHeal.
Official Riot Games Data Dragon, version 16.20.1, ja_JP champion metadata.

- Documentation: https://developer.riotgames.com/docs/lol#data-dragon
- Champion metadata: https://ddragon.leagueoflegends.com/cdn/16.20.1/data/ja_JP/champion/{ChampionId}.json
- Spell images: https://ddragon.leagueoflegends.com/cdn/16.20.1/img/spell/{ImageName}.png
- Passive images: https://ddragon.leagueoflegends.com/cdn/16.20.1/img/passive/{ImageName}.png

Images and names are Riot Games assets. This unofficial training prototype is not endorsed by Riot Games. All gameplay, simplified effects, and HUD code are custom. Reference cooldowns in ability-data.js are source metadata; runtime rules in abilities.js intentionally use training cooldowns, normalized mana, and simplified mechanics.
